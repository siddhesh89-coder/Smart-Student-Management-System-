# Student Record and Academic Management System

## About the Project

This project is developed using Python to demonstrate how Python collections can be used to organize and manage student academic records.

## Objectives

* Store and manage student information.
* Add, search, update, and delete student records.
* Calculate individual and overall average marks.
* Identify the highest-scoring student.
* Search students by department.
* Demonstrate lists, tuples, sets, and dictionaries.

## Technologies Used

* Python 3
* Python collections
* VS Code

## Project Structure

* `application/` — Main Python application.
* `documentation/` — Project report, test cases, and screenshot checklist.
* `programs/` — Additional programs, if applicable.
* `screenshots/` — Screenshots showing program execution.

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:

   `py application/student_management.py`

## Important Note

Student records are stored in memory while the program is running. The data resets when the program is restarted.
